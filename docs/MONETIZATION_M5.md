# Phase M5 - Branding And Go To Market Assets

## Goal

Preparar SQX Edge Pro para poder explicarse, ensenarse y venderse sin prometer resultados financieros.

M5 no activa cobros ni licencias reales. Su objetivo es que el producto tenga una historia comercial coherente antes de construir enforcement duro.

## Brand Positioning

Nombre comercial recomendado:

- SQX Edge Pro

Categoria:

- herramienta local profesional para usuarios de StrategyQuant X

Tagline:

- De idea a pipeline operativo SQX con menos friccion.

Propuesta principal:

- Convierte generacion, limpieza, validacion y seguimiento de estrategias SQX en un flujo guiado, portable y trazable.

Promesa segura:

- menos trabajo repetitivo
- menos errores operativos
- mas trazabilidad
- mejor entrega local
- experiencia portable de un click

Promesas prohibidas:

- beneficios garantizados
- estrategias ganadoras
- rentabilidad asegurada
- resultados financieros garantizados

## Demo Script

Video demo recomendado: 90-120 segundos.

Guion:

1. Inicio: cockpit y readiness.
2. Por Categoria: edge map colapsado y navegable.
3. Pipeline State: plan de minings y tracking.
4. Project Generator: API local, rutas SQX y generacion.
5. Strategy Cleaner: preview antes de aplicar cambios.
6. Estrategias: repositorio, filtros, import/export.
7. Cierre: portable, local, Pro opcional.

No mencionar beneficios financieros. Cerrar con productividad y trazabilidad.
