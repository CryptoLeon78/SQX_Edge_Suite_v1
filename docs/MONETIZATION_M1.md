# Phase M1 - Monetization Model

## Positioning

SQX Edge Suite Pro debe venderse como una herramienta profesional para usuarios de StrategyQuant X que quieren convertir un proceso disperso de seleccion, generacion, limpieza y validacion de estrategias en un flujo operativo guiado.

Promesa principal:

> De idea a pipeline operativo SQX con menos friccion, mas trazabilidad y entregables listos para trabajar.

No debe prometer rentabilidad ni resultados financieros. La venta debe centrarse en productividad, organizacion, reduccion de errores, repetibilidad y soporte del flujo de trabajo.

## Target Users

### Primary

Usuarios individuales de StrategyQuant X que ya generan estrategias y necesitan orden:

- traders sistematicos retail avanzados
- usuarios de SQX que se pierden entre plantillas, exports y validaciones
- perfiles no programadores que valoran una herramienta portable
- usuarios que quieren reducir trabajo manual repetitivo

### Secondary

Usuarios mas avanzados que comprarian extras:

- builders de portfolios
- pequenos equipos de investigacion
- consultores que preparan estrategias para terceros
- usuarios que quieren plantillas y presets listos

## Product Lines

### SQX Edge Free

Objetivo: permitir probar la app, entender el flujo y generar confianza.

Incluye:

- dashboard visual
- Inicio / cockpit
- vistas de activos, categorias y filtros
- workflow basico
- lectura de manifiestos
- ejemplos de estrategias
- export CSV basico
- release portable para uso personal

Limitaciones recomendadas:

- Project Generator bloqueado o limitado a demo
- Strategy Cleaner bloqueado o limitado a preview
- sin presets premium
- sin soporte prioritario
- sin packs comerciales

### SQX Edge Pro

Objetivo: producto principal de pago.

Incluye:

- Project Generator completo
- Strategy Cleaner completo
- backups/restauracion de estado
- export avanzado
- workflows premium
- perfiles de generacion
- validaciones guiadas
- release/checklist profesional
- actualizaciones durante la suscripcion
- soporte opcional segun plan

### Services

Servicios alrededor de la herramienta:

- instalacion y puesta en marcha
- configuracion SQX + paths + templates
- revision de pipeline del usuario
- adaptacion de plantillas
- sesion 1:1 de onboarding
- diagnostico de problemas de generacion
- configuracion de entorno portable

### Templates And Packs

Productos digitales adicionales:

- packs de templates Capa 1 / Capa 2
- presets de filtros por mercado
- workflows premium por tipo de activo
- packs de perfiles de generation/retest
- ejemplos comentados
- checklist profesional de validacion

## Pricing Recommendation

Precios iniciales recomendados para validar mercado sin sobrecomplicar.

### Pro Monthly

Precio recomendado: 19-29 EUR/mes.

Uso:

- entrada accesible
- ideal para usuarios que quieren probar
- soporte comunitario o limitado

Recomendacion inicial: 24 EUR/mes.

### Pro Annual

Precio recomendado: 190-240 EUR/ano.

Uso:

- descuento frente a mensual
- mejor caja
- reduce churn

Recomendacion inicial: 199 EUR/ano.

### Pro Plus Support

Precio recomendado: 49-79 EUR/mes o 399-599 EUR/ano.

Incluye:

- todo Pro
- soporte prioritario
- ayuda de setup
- revision periodica limitada
- acceso temprano a packs

Recomendacion inicial: no lanzarlo de inmediato como plan publico. Ofrecer soporte como add-on manual.

### Setup Service

Precio recomendado: 99-199 EUR pago unico.

Incluye:

- instalacion guiada
- configuracion SQX local
- prueba de Project Generator
- entrega funcionando

Recomendacion inicial: 149 EUR pago unico.

### Template Packs

Precio recomendado:

- pack pequeno: 29-49 EUR
- pack premium: 79-149 EUR

Recomendacion inicial: crear primero 1 pack premium de 79 EUR.

## Messaging

Mensajes seguros:

- "Ahorra horas de trabajo manual preparando proyectos SQX."
- "Reduce errores de rutas, plantillas y exports."
- "Mantiene tu pipeline documentado y repetible."
- "Portable, local y pensado para usuarios no tecnicos."

Mensajes a evitar:

- promesas de beneficios
- "estrategias ganadoras garantizadas"
- "rentabilidad asegurada"
- claims financieros no verificables

## Validation Plan

Antes de construir licencias complejas:

1. Crear una version Free clara.
2. Preparar demo visual Pro.
3. Publicar landing simple.
4. Ofrecer acceso Pro manual a primeros usuarios.
5. Validar si pagan mensual/anual.
6. Recoger dudas de soporte.
7. Solo despues, implementar licencia mas robusta.
