# SQX Edge Pro - Commercial README Draft

SQX Edge Pro es una herramienta local para usuarios de StrategyQuant X que quieren organizar su pipeline de investigacion, generacion, limpieza y validacion de estrategias desde una interfaz portable.

## What It Does

- Organiza activos, categorias y configuraciones SQX.
- Convierte un plan de minings en Custom Projects `.cfx`.
- Ayuda a limpiar estrategias `.sqx` con preview antes de aplicar cambios.
- Mantiene un cockpit operativo con readiness, pipeline y trazabilidad.
- Funciona localmente y se abre con doble click.

## Free vs Pro

SQX Edge Free:

- dashboard
- Inicio cockpit
- activos, categorias y filtros
- estrategias basicas
- Project Generator demo
- Strategy Cleaner preview

SQX Edge Pro:

- Project Generator completo
- Strategy Cleaner aplicando cambios
- import/export avanzado
- workflows premium
- backups avanzados
- acceso a packs compatibles

## Installation

1. Descargar el ZIP portable.
2. Descomprimir en una carpeta normal.
3. Hacer doble click en `START_SQX_EDGE.bat`.
4. Abrir Inicio.
5. Activar licencia Pro cuando este disponible.

No hace falta instalar Python.

## Responsible Notice

SQX Edge Pro no promete rentabilidad ni resultados financieros. La herramienta ayuda a mejorar productividad, orden, repetibilidad y trazabilidad dentro de un flujo StrategyQuant X.
