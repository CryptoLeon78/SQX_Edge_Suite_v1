# SQX Edge Pro - Commercial README

SQX Edge Pro is sold as protected web access for StrategyQuant X workflows. The buyer opens a private link, validates email, enters an active Pro session and works inside an isolated server-side workspace. The user does not install Python, configure local SQX paths or run a Windows launcher as the commercial onboarding path.

## What It Does

- Guides the SQX Edge methodology from asset selection to final decision.
- Organizes Activos, Mining Control, SQX Views, Project Generator, Template Maker, Strategy Control and Champion vs Challenger.
- Generates `.cfx`, `.vw`, C2 templates and review/export artifacts from a controlled server environment.
- Keeps traceability for asset, timeframe, BlockSetting, template, metrics contract, cluster, strategy and final artifact.
- Gives support a redacted audit trail instead of asking the buyer to send sensitive local folders.

## Buyer Path

1. Buyer chooses monthly or annual access.
2. Payment webhook activates or renews `paid_subscription`.
3. Buyer receives the protected access link through an approved private channel.
4. Cloudflare Access validates email before the app body is visible.
5. SQX Edge validates the app session, entitlement and security policy.
6. The server derives the buyer workspace.
7. The buyer works in the browser and exports approved artifacts from that workspace.

## What The Buyer Does Not Do

- No Python install.
- No ZIP download as the primary commercial path.
- No local launcher.
- No manual SQX path setup.
- No local `data.db` or BlockSettings copy from the buyer machine.

Portable packaging remains an internal rollback/support fallback, not the buyer promise.

## Tester Access

Approved testers use `tester_free`. They can access the complete tool while the grant is active, but they still authenticate, receive a workspace, leave an audit trail and can be revoked. More testers can be added later through the same controlled path.

## Support Scope

Support can help with:

- access and session issues;
- workspace readiness;
- dashboard orientation;
- Project Generator, SQX Views and Template Maker workflow;
- interpreting validation messages;
- redacted support bundles.

Support does not provide financial advice, trading execution instructions, profit guarantees or risk-free claims.

SQX Edge Pro does not promise profitability or financial results. It sells productivity, methodology, traceability and reduced operational error around StrategyQuant X research.
